# Advanced Usage

Take your UI to the next level with advanced features—no coding required!

## Conditional Logic

Show or hide components and sections based on user actions or data.

- Use the ConditionalPanel to set up rules.
- Example: Show a section only after a form is submitted.

## Popups & Modals

Create overlays and dialogs for alerts, forms, or extra info.

- Use the PageSettingsPanel to enable popup mode and set options.
- Example: Open a modal when a button is clicked.

## Data Transfer

Pass data between screens or components for dynamic workflows.

- Use the DataTransferPanel to set up what data is sent and where.
- Example: Send selected row data from a table to a detail page.

## Validation

Add rules to ensure users enter valid data.

- Use the InputValidationPanel to set required fields, patterns, and error messages.
- Example: Require an email address and show an error if it’s missing.

## Interceptors & Custom Logic

Add advanced logic for data manipulation or event handling.

- Use the InterceptorsPanel to trigger actions before/after API calls or user events.
- Example: Automatically format data before saving.

## Best Practices

- Preview your UI often to test logic and workflows.
- Use panels for all configuration—no need to edit JSON directly.
- Save regularly and re-use configurations for similar workflows.
- Use advanced panels for dynamic, interactive UIs.
