# Overview

The UI Configurator is designed for users who want to build and manage business application UIs visually. You don’t need to know anything about the underlying DSL or JSON—just follow these steps to create your own screens and workflows.

## Main Workflow

1. **Start a New Project**: Open the UI Configurator and create a new configuration or load an existing one.
2. **Add Pages**: Each page represents a screen in your application (e.g., dashboard, form, list).
3. **Add Sections**: Organize components into sections for better layout and logic grouping.
4. **Drag & Drop Components**: Choose from tables, headings, spacers, workflow stages, and more. Place them where you want.
5. **Edit Properties**: Click any component to open its property panel. Use the panel controls to change text, layout, data sources, logic, and more.
6. **Set Up Logic**: Use panels to add conditional visibility, popups, data transfer, and validation.
7. **Preview**: Instantly see your UI and test interactions.
8. **Save & Export**: Save your work. The tool stores your configuration for future editing or integration.

## Example Use Cases

- Loan account dashboards
- Disbursement worklists
- Application queues and login screens
- Data entry and review forms
- Custom popups and modals

## No Coding Required

All configuration is done visually. You never need to edit JSON or DSL files directly. The tool handles everything behind the scenes.
