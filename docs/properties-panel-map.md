# Properties Panel Map

The Properties Panel Map helps you visually edit advanced logic and configuration for your UI. You don’t need to know how things work under the hood—just use the panels!

## How to Edit Advanced Logic

- **ConditionalPanel**: Show/hide sections or components based on user actions or data.
- **DataTransferPanel**: Pass data between screens or components for dynamic workflows.
- **PageSettingsPanel**: Set up popups, overlays, and page-level settings.
- **InterceptorsPanel**: Add custom logic for data manipulation or event handling.

## Example: Creating a Popup

1. Select the page or section you want to show as a popup.
2. Use the PageSettingsPanel to enable popup mode, set width, and configure close behavior.
3. Preview your popup instantly.

## Example: Conditional Visibility

1. Select a section or component.
2. Use the ConditionalPanel to set rules for when it should be visible.
3. Preview and test your logic.

## Example: Data Transfer

1. Select the component or page where you want to pass data.
2. Use the DataTransferPanel to set up what data is sent and where.
3. Preview and test the workflow.
