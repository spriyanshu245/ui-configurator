# Property-to-Panel Mapping

Each property is edited using a specific panel. This mapping ensures you always see the right controls for the property you want to change.

## How It Works

- Select a component.
- The UI Configurator automatically opens the correct panel for the property you want to edit.
- For example, text properties open the TextPanel, layout properties open the LayoutPanel, and so on.

## Common Mappings

- **Text** → TextPanel
- **Width/Height/Columns** → LayoutPanel
- **Icon** → IconPanel
- **API/Action** → ActionPanel
- **Data Source/Options** → DataPanel
- **Style** → StylePanel
- **Conditional Logic** → ConditionalPanel
- **Validation** → InputValidationPanel
- **Popup Settings** → PageSettingsPanel
- **Data Transfer** → DataTransferPanel

## Example: Editing a Button

- Select the button component.
- Use the ActionPanel to set up what happens when the button is clicked (API call, navigation, etc.).
- Use the StylePanel to change its color and border.
- Use the ConditionalPanel to show/hide the button based on user actions.
